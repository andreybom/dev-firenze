# Migrações do banco

Coloque aqui as migrações SQL versionadas do Flyway, usando o formato `V<versão>__<descricao>.sql` (por exemplo, `V1__criar_estrutura_inicial.sql`).

A primeira migração de domínio será criada após a aprovação da arquitetura e do modelo inicial no marco M1. Não faça alterações manuais no esquema compartilhado; o Hibernate está configurado somente para validá-lo.
